# Password Manager — менеджер паролей

## 1. Назначение проекта

Password Manager — консольное приложение на Python для локального хранения логинов и паролей.

Программа позволяет создать хранилище с мастер-паролем, войти в него, добавлять записи, просматривать список сайтов, получать сохранённые логины и пароли, удалять записи и генерировать новые пароли.

Данные сохраняются в файле `vault.json` в зашифрованном виде.

## 2. Как работает защита данных

- **Мастер-пароль** — пароль, с помощью которого пользователь открывает хранилище. Он не сохраняется в открытом виде.
- **Соль** — случайная последовательность байтов, которая создаётся при создании хранилища. Она помогает безопасно сформировать ключ из мастер-пароля.
- **PBKDF2-HMAC-SHA256** — алгоритм, который на основе мастер-пароля и соли формирует проверочный хэш и ключ шифрования. Используется 600 000 итераций.
- **Fernet** — механизм библиотеки `cryptography`, который шифрует и расшифровывает записи, а также проверяет, что зашифрованные данные не были изменены.
- **getpass** — скрывает вводимые пароли в терминале.

## 3. Основные файлы проекта

- `password_manager/manager.py` — класс `PasswordManager`. Здесь находится основная логика: создание хранилища, проверка мастер-пароля, работа с записями, шифрование и генерация паролей.
- `password_manager/cli.py` — запуск программы и консольное меню. Этот файл принимает команды пользователя и вызывает методы класса.
- `password_manager/__init__.py` — обозначает папку `password_manager` как Python-пакет.
- `tests/test_manager.py` — автоматические тесты основных функций.
- `.github/workflows/ci.yml` — настройки автоматического запуска проверок на GitHub.
- `pyproject.toml` — сведения о проекте, зависимостях и настройках инструментов.
- `.gitignore` — список файлов, которые Git не должен добавлять в репозиторий.

## 4. Основные методы класса `PasswordManager`

| Метод | Назначение |
|---|---|
| `__init__(vault_path)` | Создаёт объект менеджера и задаёт путь к файлу хранилища. |
| `_derive_keys(password, salt)` | Формирует из мастер-пароля и соли проверочный хэш и ключ шифрования. |
| `init_master(password)` | Создаёт новое хранилище и устанавливает мастер-пароль. |
| `unlock(password)` | Проверяет мастер-пароль. Если он верный, расшифровывает записи и открывает хранилище. Возвращает `True` или `False`. |
| `add_entry(name, login, pwd)` | Добавляет новую запись или заменяет существующую, после чего сохраняет данные в зашифрованном виде. |
| `list_entries()` | Возвращает названия сохранённых записей, не показывая пароли. |
| `get_entry(name)` | Находит запись по названию и возвращает логин и пароль. |
| `delete_entry(name)` | Удаляет запись. Возвращает `True`, если запись найдена и удалена, иначе `False`. |
| `generate_password(length)` | Создаёт случайный пароль из строчных и заглавных букв, цифр и специальных символов. |
| `_require_unlocked()` | Проверяет, открыто ли хранилище, и не позволяет работать с записями до входа. |
| `_persist()` | Шифрует все записи и сохраняет их в `vault.json`. |
| `_persist_new_vault()` | Записывает в файл новое пустое хранилище. |
| `_write_vault()` | Безопасно записывает данные в файл через временный файл с последующей заменой. |

Методы, начинающиеся с `_`, являются внутренними: они нужны для работы программы и обычно не вызываются пользователем напрямую.

## 5. Работа консольного интерфейса

В файле `cli.py` находятся три основные функции:

- `build_parser()` — настраивает аргументы командной строки, например `--init`, `--unlock` и `--generate`.
- `run_menu(manager)` — показывает меню и обрабатывает выбор пользователя: добавить запись, показать список, получить пароль, удалить запись, сгенерировать пароль или выйти.
- `main()` — главная функция запуска. Она проверяет, существует ли хранилище, организует создание или вход и затем запускает меню.

Перед показом сохранённого пароля программа дополнительно просит повторно ввести мастер-пароль.

## 6. Установка и запуск

Требуется Python 3.11 или новее.

Установка проекта и необходимых библиотек:

```powershell
py -m pip install -e ".[dev]"
```

Создание хранилища:

```powershell
py -m password_manager.cli --init
```

Вход в существующее хранилище:

```powershell
py -m password_manager.cli --unlock
```

Запуск без аргументов:

```powershell
py -m password_manager.cli
```

Генерация пароля длиной 20 символов:

```powershell
py -m password_manager.cli --generate
```

Генерация пароля длиной 28 символов:

```powershell
py -m password_manager.cli --generate --length 28
```

## 7. Проверка проекта

Для проверки используются:

```powershell
py -m pytest
py -m ruff check .
py -m ruff format --check .
py -m mypy --strict password_manager
```

- `pytest` запускает автоматические тесты.
- `ruff` проверяет стиль и форматирование кода.
- `mypy` проверяет корректность типов.

GitHub Actions запускает проверки автоматически при отправке изменений в репозиторий и при создании pull request.

## 8. Итог

В результате создан локальный менеджер паролей с мастер-паролем, шифрованием данных, управлением записями и генератором паролей. Основная логика отделена от консольного интерфейса, а корректность работы проверяется автоматическими тестами.

**Важно:** файл `vault.json` содержит данные хранилища. Он добавлен в `.gitignore` и не должен загружаться в публичный репозиторий GitHub.
